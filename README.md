## 01 / Perfil

Neste perfil, o sistema aparece inteiro: o que o usuário vê, o que a API responde e onde os dados são organizados.

Os projetos públicos combinam **React e TypeScript** no frontend com **Python e FastAPI** no backend, usando **PostgreSQL**, **Docker** e um fluxo de desenvolvimento documentado.

## 03 / Em construção

### Cosmetics Hub

Um MVP de gestão comercial para empresas de cosméticos, dividido em dois repositórios:

| Camada | Repositório | Estado atual |
| --- | --- | --- |
| API | [distribution-hub-api](https://github.com/lc-curto/distribution-hub-api) | `GET /health`, teste automatizado e PostgreSQL configurado para desenvolvimento local |
| Web | [distribution-hub-web](https://github.com/lc-curto/distribution-hub-web) | Scaffold do frontend |

O roadmap parte da preparação do ambiente e avança para banco, identidade, empresas e clientes. Catálogo, estoque, pedidos e recebíveis fazem parte do escopo documentado para etapas posteriores.

[Ver roadmap de aprendizagem e desenvolvimento →](https://github.com/lc-curto/distribution-hub-api/blob/main/docs/learning-roadmap.md)
