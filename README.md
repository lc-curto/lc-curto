## A ideia por trás dos projetos

Não é uma lista solta de tecnologias. Cada peça aparece em um projeto público: interface, API, banco, ambiente e documentação trabalhando na mesma direção.

O ponto de partida é simples — um `GET /health` que funciona localmente e tem teste. A partir dele, o sistema ganha novas camadas sem esconder o que ainda está por fazer.
