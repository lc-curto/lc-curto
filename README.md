## Sobre este perfil

- Projeto principal público: **Cosmetics Hub**, um MVP de gestão comercial para empresas de cosméticos.
- O projeto possui frontend separado em React/TypeScript e backend em FastAPI/Python.
- A documentação do projeto registra requisitos, arquitetura, domínio, API e um roadmap de aprendizagem e desenvolvimento.
- O estado atual da API está documentado no próprio repositório; funcionalidades descritas como especificadas ainda não devem ser tratadas como implementadas.

## Projetos públicos

### Cosmetics Hub

MVP de gestão comercial para empresas de cosméticos. O projeto está dividido em dois repositórios:

- [Frontend — distribution-hub-web](https://github.com/lc-curto/distribution-hub-web)
- [Backend — distribution-hub-api](https://github.com/lc-curto/distribution-hub-api)

A documentação do backend registra como próximos módulos: autenticação, empresas, clientes, catálogo, estoque, pedidos e recebíveis. Ela também diferencia o que está implementado, especificado e ainda por definir.

### Portifolio

Repositório público com o portfólio em HTML e CSS.

- [Acessar o repositório Portifolio](https://github.com/lc-curto/Portifolio)

## Roadmap documentado

O roadmap do Cosmetics Hub define um ciclo de **entender, observar, praticar, explicar, aplicar e testar** antes de avançar para a próxima etapa. A fila atual começa pela preparação do ambiente e pela execução local da API.

- [Ver roadmap de aprendizagem e desenvolvimento](https://github.com/lc-curto/distribution-hub-api/blob/main/docs/learning-roadmap.md)
